# 本地数据校验

## 读取规则

- 先检查文件大小、编码/BOM、分隔符、引号规则、表头和样本，保留原件。不能直接用逗号切分 CSV；字段可能包含分隔符、引号或换行。
- 账号、证件号、机构码和编号默认按字符串保留前导零及长数字。金额按十进制定点口径处理，明确币种、单位与舍入规则。
- 区分缺失字段、NULL、空字符串、空白和数值零。日期格式、时区、有效值范围由规则或用户资料决定，不凭样本臆造。

## 最小校验流程

1. 列出输入文件、业务粒度、预期字段、主键及核对规则；没有业务规则时只做结构与事实统计。
2. 用现有运行时和标准库进行逐行校验，记录逻辑记录号、字段、原因及必要的脱敏样本。说明带换行的 CSV 中记录号与物理行号不同。
3. 汇总总记录数、有效/异常记录数、各类异常计数与空值统计；一个记录有多种异常时分别报告，避免加总后误当异常行数。
4. 检查重复键和关联缺失。大文件优先流式聚合；全局去重需要保存键时估计内存，可使用已有 SQLite 或分块外部排序。仅抽样时明确样本范围，不承诺全量无重复。
5. 对比输出与原始记录数、金额总和及关键字段。清洗须得到用户任务授权，另存结果，说明改变了哪些值；无法确定的值保留并标记。

## 交付边界

交付简短统计、规则来源、问题清单路径和实际验证范围。导出供表格软件查看的文本时处理公式注入风险，同时保留机器可复核的原始值映射。

不自动下载 pandas、数据库驱动或其他依赖。XLSX、DOCX、PDF 需要当前环境已有的适用工具；缺少工具时请求可读取的导出格式，不将改扩展名的文本冒充 Office 文件。原始数据不上传公网。
